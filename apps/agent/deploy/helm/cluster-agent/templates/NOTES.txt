backend gRPC endpoint:

  {{ .Values.backend.grpcAddr | default "(install 시 backend 가 자동 주입)" }}

이 endpoint 가 잘못되어 있으면 agent pod 가 backend 에 연결을 못해 CrashLoopBackOff 가능.
backend 의 application.yaml 의 `agent.grpc.public-endpoint` 설정 확인 권장.

{{- if not (or .Values.bootstrap.registrationToken .Values.bootstrap.existingSecret) }}

⚠️  bootstrap.registrationToken / bootstrap.existingSecret 둘 다 비어있음.
    Pod 가 secret 을 못 찾아 CreateContainerConfigError 가 됩니다.
    하나는 반드시 지정 필요:

    A. chart 가 secret 생성:
       --set bootstrap.registrationToken="<backend 에서 받은 JWT>"

    B. 외부에서 만든 secret 사용:
       kubectl -n {{ .Values.agent.namespace }} create secret generic aipaas-agent-bootstrap \
           --from-literal=registration-token='<JWT>'
       그리고 --set bootstrap.existingSecret=aipaas-agent-bootstrap
{{- end }}
